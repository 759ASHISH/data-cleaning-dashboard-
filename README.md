# Data Cleaning and Dashboard Visualization Project

This project focuses on cleaning datasets and visualizing them using interactive dashboards with charts such as bar graphs, line graphs, and pie charts. It uses Python libraries such as `pandas`, `matplotlib`, and `plotly` for data manipulation and visualization.

## Features
- **Data Cleaning**: The script loads datasets (in Excel format), cleans the data by handling missing values, incorrect formats, and standardizing columns.
- **Data Visualization**: It generates dynamic and interactive dashboards with various types of graphs.
- **File Export**: After cleaning the data, it exports the cleaned data to CSV format.
- **Interactive Dashboard**: Visualizes the cleaned data using a clean and simple interface that displays the data charts interactively.

## Technologies Used
- **Python 3.13**: The core programming language for this project.
- **pandas**: For data manipulation and cleaning.
- **matplotlib**: For creating static, animated, and interactive visualizations.
- **plotly**: For interactive and dynamic visualizations.
- **dash**: To create a clean interface to visualize and interact with data.

## Installation

### Prerequisites
- Python 3.13.x (or higher)
- VS Code (or any Python IDE of your choice)

Clone the repository and run the main script:
python main_dashboard.py
